# Avionic Fontbook

Source projects for the GM avionic-display font families.

## Font families

| Directory | Family | Upstream basis | License | Status |
| --- | --- | --- | --- | --- |
| [`SansSerif/`](SansSerif/) | GM SansSerif | Noto Sans | SIL Open Font License 1.1 | Regular, Bold, and Light Birdfont sources |
| [`SansSlab/`](SansSlab/) | GM SansSlab | Tomorrow Medium | SIL Open Font License 1.1 | Directory reserved for the upcoming family |

Each family directory contains its own license and source notice. The
repository-level [`LICENSE`](LICENSE) applies the SIL Open Font License 1.1
to the Font Software distributed in this repository.
