# GM SansSerif

This directory contains the Birdfont source projects for the GM SansSerif
family:

- `GM_SansSerif_Regular.birdfont`
- `GM_SansSerif_Bold.birdfont`
- `GM_SansSerif_Light.birdfont`

GM SansSerif is a modified font project based on Noto Sans. The source
projects and their derivatives are distributed under the SIL Open Font
License, Version 1.1. See [`LICENSE-OFL-1.1.txt`](LICENSE-OFL-1.1.txt).
